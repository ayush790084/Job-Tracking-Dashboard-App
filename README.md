## 💼✨ Job Tracking Dashboard
🚀 A modern and responsive **Job Tracking Dashboard** built using **React.js** to help users manage and track job applications efficiently.

---

## 🌟 Live Features & Demo
https://jobtrackingdashboard.vercel.app/

✨ Add new job applications  
📊 Track status → Applied | Interview | Rejected  
🔍 Search & filter by company or role  
📌 Smart dashboard stats (Total / Selected / Rejected)  
💾 Data stored in **localStorage (No Backend Needed)**  
🎨 Clean, minimal & responsive UI

## ⚙️ Setup & Run

# Clone repo
```
git clone https://github.com/your-username/job-tracker-dashboard.git
```
# Go to project
```
cd job-tracker-dashboard
```
# Install dependencies
```
npm install
```
# Start app
```
npm start
```

## 🧠 How It Works

* Users can add job details (company, role, status)

* Data is stored in browser using localStorage

* Dashboard shows real-time job statistics

* Filter/search helps manage applications easily
